# HOLBERY Marketplace

A product-owned digital marketplace and distribution platform for original HOLBERY digital products, tools, templates, workbooks, guides, and software.

## Project status

Documentation-first foundation. Architecture and requirements are being defined before implementation. No payment provider, marketplace policy, deployment, or customer-facing feature is considered production-ready until verified.

## Scope boundaries

This repository owns the HOLBERY Marketplace storefront, product catalog, product delivery, distribution workflows, and marketplace analytics. HOLBERY Intelligent OS (HIO) remains a separate system. Bozq One System is private to Bosku Cukur and is out of scope. Do not copy secrets, customer data, or internal HIO/Bozq data into this repository.
